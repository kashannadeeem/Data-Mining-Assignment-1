# Data-Mining-Assignment-1
# UK Gaming Console Sales and Seasonal Promotion Analytics

## Project Overview

This project focuses on designing a relational database to analyse UK gaming console sales and seasonal promotional activities across 2025 and 2026 (up to 25 October 2026).

The dataset contains four interconnected tables: **Consoles, Promotions, Customers and Sales**, with 16 console models, 8 promotional campaigns, 1,500 synthetic customers and 1,500 sales transactions.

## Technologies Used
- **Python:** Data generation and processing.
- **Pandas:** DataFrame creation and CSV export.
- **NumPy:** Random data generation and selection.
- **Faker:** Synthetic UK-style customer information.
- **SQLite:** Relational database creation and management.

## Key Features
- Primary keys, foreign keys and composite unique constraints.
- Synthetic UK customer and sales data.
- Seasonal promotional campaigns and discount calculations.
- Deliberate repeated and missing values for data-quality practice.
- A 15% assumed console price increase in 2026 to model potential rising memory component costs.

## Project Objective

The main objective is to practise synthetic data generation, relational database design, SQL constraints, data quality management and sales analytics using a realistic retail scenario.
